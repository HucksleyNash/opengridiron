## Affected Pages and Routes

- `/draft/:leagueId` — mock setup ranking synchronization, readiness, automatic opponent loop, live manual/Yahoo room, asynchronous scenario comparison, archive management, and post-draft replay.
- `POST /api/v1/leagues/{league_id}/draft-sessions` — preserve the current contract while creating mock/live configuration.
- `POST /api/v1/leagues/{league_id}/draft-rankings/sync` — start or coalesce Yahoo ranking synchronization and report progress/coverage.
- `POST /api/v1/draft-sessions/{session_id}/actions/start` — reject incomplete mock ranking/projection/position coverage.
- `POST /api/v1/draft-sessions/{session_id}/opponent-picks/next` — select and append exactly one deterministic synthetic opponent pick only in an eligible mock.
- `POST /api/v1/draft-sessions/{session_id}/events` — preserve manual, correction, owner-snapshot, order, sequence, idempotency, and completion behavior behind the shared mutation coordinator.
- `POST /api/v1/draft-sessions/{session_id}/sync/yahoo` — visible-browser single-flight polling, shadow proposals, evidence-gated authority, and recovery.
- `POST /api/v1/draft-sessions/{session_id}/simulations` and `GET /api/v1/draft-sessions/{session_id}/computations/{run_id}` — persisted asynchronous lifecycle and stale publication guards.
- `GET /api/v1/draft-sessions/{session_id}/recommendations` — complete owner decision surface, persisted forecast state, freshness, and deterministic explanations.
- `GET /api/v1/draft-sessions/{session_id}/replay` — no-hindsight scoring, waiver add/drop pairs, separate mock/live coaching, and replay generations.
- `GET /api/v1/draft-sessions/{session_id}/diagnostics` — redacted state, versions, hashes, source/job health, and integrity results.

## Key Interactions to Verify

- Open a mock with no rankings; automatic Yahoo sync starts once, Start stays disabled, progress/coverage renders, and a successful complete snapshot unlocks Start.
- Reopen setup within 24 hours; the complete snapshot is reused immediately. Refresh now creates a new immutable snapshot without rewriting an active session.
- Start an automatic mock; server-selected opponent picks advance one at a time and stop exactly on every owner turn.
- Pause, reload, navigate away/back, open a second tab, lose a response, and switch to manual-opponent mode without duplicate or out-of-order picks.
- Attempt synthetic advancement in live, paused, completed, owner-turn, Yahoo-shadow, and Yahoo-authoritative sessions; every request is rejected without mutation.
- Record any legal owner player, including a player outside the displayed shortlist, and verify exact at-time replay scoring after later projection/ranking/news changes.
- Run scenario comparison; observe queued/running/ready states, cancel on board change, recover from timeout/worker restart, and rerun explicitly.
- Complete a draft; verify compatible waiver add/drop pairs and coaching evidence that never mixes mock and live sessions.
- Exercise archive/restore, correction, pause/resume, early completion, reopen generation, Yahoo proposal resolution, and manual operation with all optional capabilities disabled.

## Edge Cases

- Yahoo login redirect, expired cookie, timeout, `429 Retry-After`, changed/missing rank header, duplicate rank, missing identity, partial pagination, suspicious empty response, and concurrent setup tabs.
- Exactly enough players for the configured picks; one player short; insufficient QB/RB/WR/TE/DEF/K coverage; 8/16 teams; 1/30 rounds; odd/even snake reversals; owner in every slot.
- Equal opponent scores, negative VOR, exhausted position, roster limits, full 480-pick mock, stable policy tie-break, and byte-for-byte repeatability.
- Stale sequence, stale recommendation, same idempotency key retry, different key race, two tabs, DB busy timeout, correction of superseded/provider-confirmed pick, and process restart after commit before recommendation publication.
- Import preview restart, TTL expiry, double commit, changed hash, identity remap, transaction rollback, oversize/deep/formula/non-finite input, and cleanup.
- Simulation duplicate request, fewer than 100 playouts, 500 playout bound, cancellation, timeout, worker exit, interrupted restart, stale input hash, and repeat seed equality.
- Replay choice outside top ten, corrected/reopened/early-completed session, missing/hash-mismatched snapshot, later injury/news/rank change, incompatible drop candidate, exactly 2/3 sessions in each evidence lane, and no history.
- Prompt injection, unsupported injury/probability/score claim, conflicting/stale evidence, missing citations, malformed schema, refusal, timeout, and oversized explanation dossier.

## Critical Paths

- Automatic 12-team mock: setup -> rank sync -> readiness -> start -> automatic opponent runs -> every owner decision -> completion -> exact replay/waiver/coaching.
- Live Yahoo shadow: setup -> immediate catch-up -> automatic visible polling -> exact confirmations/proposals -> manual recovery during outage -> reconciliation -> completion.
- Canonical mutation race: manual pick + synthetic request + Yahoo reconciliation + two-tab retry at one sequence -> one committed event and precise recovery for every loser.
- Worker recovery: scenario queued/running -> application restart -> interrupted state -> deterministic advice remains -> explicit rerun -> current-sequence publication only.
- Cutover: backup -> additive migration -> flag-off parity -> container frontend/backend/eval/performance gates -> flag-on smoke -> rollback drill with current canonical history preserved.
